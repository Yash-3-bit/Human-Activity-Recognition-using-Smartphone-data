# Human Activity Recognition (HAR) Using Smartphone Data
This project leverages smartphone sensor data to recognize human activities such as walking, running, sitting, and standing. The dataset used is collected from embedded sensors (accelerometers and gyroscopes) in smartphones, offering a rich set of features to classify activities using machine learning techniques.

# Features
Dataset: Utilizes the UCI HAR Dataset, which includes labeled data collected from smartphone accelerometers and gyroscopes.
Machine Learning Models: Implements various classification algorithms such as Logistic Regression, Random Forests, and Neural Networks for activity recognition.
Data Preprocessing: Includes feature extraction, normalization, and handling missing data.
Evaluation: Provides detailed evaluation metrics like accuracy, precision, recall, and F1-score to assess model performance.
Visualization: Offers visual insights into sensor data, feature importance, and model performance.

# Technologies Used
